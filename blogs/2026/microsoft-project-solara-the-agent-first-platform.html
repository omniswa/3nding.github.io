Microsoft Project Solara: The Agent-First Platform

June 15, 2026 7-Minute Read

There are no apps on Project Solara. No browser. No desktop. No app store. For a platform announced by the company that built Windows, that is the most clarifying detail you need to understand what Microsoft actually revealed at Build 2026 on June 2nd.

Project Solara is a chip-to-cloud software platform built from the ground up for AI agents, not apps. [H2S Media] That sentence sounds like marketing until you realize Microsoft is saying it about hardware they’ve already built, tested internally with hundreds of employees, and handed to major retailers and hospitals for pilots.

The Platform Doesn’t Run Windows — and That’s the Point

Solara runs on a new, lightweight OS built on AOSP — not Windows — that Microsoft calls the Microsoft Device Ecosystem Platform, or MDEP. It’s designed to be invisible, hosting an Agent Shell that can dynamically load and tailor multiple cloud-based agents. [Windows Central]

This is a meaningful choice, not an oversight. Microsoft chose MDEP over Windows to run on smaller, lower-power devices while retaining enterprise security and management requirements. Because MDEP is built from AOSP and is not a licensed version of Android, Microsoft cannot officially refer to it as Android. [BetaNews]

The mechanism here matters. Android’s hardware abstraction layer is mature, battle-tested across thousands of device types, and cheap to port. By building on AOSP, Microsoft gets broad chip compatibility — both Qualcomm and MediaTek ARM-based chips are already supported — without carrying the weight of a full Windows stack onto a badge-sized device.

What “Agent-First” Actually Means in Hardware

Microsoft technical fellow Stevie Bathiche framed agent-first devices as the third structure of AI integration — not AI inside your app, not AI beside your app, but AI orchestrating tasks across multiple apps and services simultaneously. [Thurrott]

The honest version: instead of a nurse typing patient notes into a laptop between consultations, a Solara badge could capture conversation, surface relevant medical records, and flag follow-up tasks — all without her opening a single application. A nurse wearing a Solara badge that captures patient interactions, surfaces relevant records, and tracks follow-up tasks is a fundamentally different value proposition from the same nurse typing into a laptop between patients. [The Next Web]

The interface adapts to the device. This is what Microsoft calls just-in-time UI. Just-in-time UI exists on a spectrum: on one end is responsive UI, highly structured interfaces that reflow predictably across screen sizes; on the other end is fully generative UI, where AI creates the interface frame by frame with minimal predefined structure. [Command Line] Solara lives somewhere in the middle right now, which is the honest answer about where the technology actually is.

The Two Devices Microsoft Showed

The badge concept is a wearable device the size of an ID badge, powered by Qualcomm hardware. It includes a camera, a fingerprint scanner, a microphone, and a speaker. A single button press wakes an AI agent. Microsoft demonstrated conversation transcription and the agent’s ability to use the badge camera to observe what the wearer is looking at. Physical privacy controls allow you to disable the camera or microphone. [4sysops]

The desk companion is closer to what you’d recognize. The smart display reference design can show information stored in Microsoft 365, like upcoming events from Outlook or data from Excel. [Engadget] It accepts voice input and has presence sensors that detect when you’re nearby. Think of it as an always-on context surface rather than a screen you have to unlock.

Bathiche said the badge was running on the Solara platform in about three days, using the same software stack as the desk device but on a different chipset from a different manufacturer. [BetaNews] That’s the whole argument for the platform: you shouldn’t have to rebuild your stack every time you change a form factor.

Three Pillars, One Security Model

The platform rests on three pillars. First, enterprise readiness: Intune device management, Entra ID authentication, Hello for Business biometrics, and physical privacy controls including a hardware mic mute button. [The Next Web]

MDEP includes patch and over-the-air updates, device integrity verification, Microsoft Defender, Intune device management, and Entra ID sign-in. [BetaNews] For IT departments already running Microsoft’s security stack, this is the key selling point. New device category, same management console. The friction of deploying entirely new hardware is one of the biggest enterprise adoption blockers — Microsoft is betting that fitting into existing Intune workflows removes that barrier.

The Pilot Companies Reveal the Target Markets

Pilot programs are planned alongside CVS Health, Best Buy, Target, Levi’s, and AccuWeather. [Windows Report] That list is deliberate. Retail floor workers, healthcare staff, logistics personnel — people whose jobs involve moving through physical space while needing information pulled from complex systems. People who can’t or won’t carry a laptop.

GitHub Copilot and Dragon Copilot, Microsoft’s healthcare AI, are both exploring agent-first experiences on the platform. [The Next Web] The healthcare angle is significant. Clinical environments have notoriously struggled with EHR interfaces that interrupt care delivery. A wearable that handles documentation passively is a decades-old aspiration with, potentially, a new technical pathway.

Microsoft Won’t Build or Sell These Devices

Microsoft will not build or sell Solara devices itself. The concept designs will become reference designs for hardware makers and industry partners to adapt for specific industries and scenarios spanning healthcare, retail, hospitality, financial services, legal, industrial, and field service. [BetaNews]

This is the classic platform play. Build the SDK, define the security model, own the cloud layer, and let hardware partners race to build on top. The business model for the platform has not been fully established beyond Bathiche confirming the devices run on Azure, with the economics still being worked out. [BetaNews] That last part deserves weight: the person presenting the platform at Build 2026 said the pricing model isn’t decided yet.

What This Is Competing Against

The wearable enterprise AI space is not empty. Humane’s AI Pin launched and struggled. Meta’s Ray-Ban glasses have found modest consumer traction. Rabbit’s R1 stumbled at launch. The graveyard of ambient AI hardware is real and recent.

What’s different with Solara is context. Microsoft already has identity management, enterprise contracts, Microsoft 365 data, and Azure infrastructure embedded into the workflows of the organizations it’s now targeting for pilots. The device is a surface for existing investment, not a standalone bet on a new behavior.

The pitch from Microsoft’s Applied Sciences Group is straightforward once you strip away the jargon: historically, creating a new device category meant rebuilding the entire technology stack from scratch. AI agents change that equation. If an agent can understand user intent and dynamically generate its own interface, developers don’t need to rearchitect everything for every new screen size or modality. [H2S Media]

That’s the actual thesis. Lower the cost of new hardware categories enough that a vertical-specific device becomes economically sensible. A badge for ER nurses. A desk display for loan officers. A wearable for retail associates. None of those markets were worth custom hardware before. They might be now.

What to Watch For Next

Project Solara is early. Microsoft is careful not to promise an immediate revolution, and the project remains in its early stages with pilot programs still being organized. [Windows Report] No hardware partner has announced a shipping product. The pricing model is unresolved. The pilots with Best Buy, CVS, and Target haven’t started yet.

The specified Qualcomm and MediaTek Arm-based chipsets are confirmed, reference designs exist, and Microsoft has noted these attributes represent current thinking that will continue to evolve. [Thurrott]

The thing worth watching isn’t whether Solara ships on schedule. It’s whether the pilot companies report that agents actually complete tasks reliably enough to change how their workers operate. Enterprise hardware lives or dies on that question. Not the demo. The Tuesday afternoon shift at a Target in Ohio.
